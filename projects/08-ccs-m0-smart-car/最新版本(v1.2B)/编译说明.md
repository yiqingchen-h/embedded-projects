## 当前引脚与用途

下表来自 `Stepping_Trace.syscfg` 的固定分配或末尾保存的引脚解；自动分配项重新生成后需再次核对。

| 实例或信号 | 引脚 | 当前用途 |
| --- | --- | --- |
| `UART_0` / UART0 | PA0 TX、PA1 RX | 串口收发；具体消息见串口业务代码 |
| `UART_1` / UART1 | PA8 TX、PA9 RX | 外部视觉通信 |
| `UART_2_L` / UART2 | PB15 TX、PB16 RX | 左电机串口 |
| `UART_3_R` / UART3 | PB2 TX、PB3 RX | 右电机串口 |
| `I2C_0` / I2C0 | PA10 SDA、PA11 SCL | 传感器总线，保存的引脚解，Fast 模式 |
| `GPIO_SPI` | PB9 SCL、PB8 SDA、PB10 RSE、PB11 DC、PB14 CS、PB26 BLK | LCD GPIO 模拟串行总线；`lcd_init.c` 逐位写总线，不是硬件 SPI0 |
| `Stepping_STEP_L` / TIMA0 CCP1 | PB20 | 左步进脉冲 |
| `Stepping_STEP_R` / TIMG0 CCP0 | PA23 | 右步进脉冲 |
| `Stepping_Gimbal_STEP_Up` / TIMG6 CCP1 | PA30 | 云台步进脉冲 |
| `Stepping_Gimbal_STEP_Down` / TIMG8 CCP0 | PB21 | 云台步进脉冲 |
| `PWM_Servos` / TIMA1 CCP0 | PA15 | 舵机 PWM |
| `Electromagnets_IO.PB17` | PB17 | 电磁铁控制 |
| SWD | PA20 SWCLK、PA19 SWDIO | 保存的调试引脚解 |

四路 UART 的目标波特率均为 115200。方向、使能、细分、按键等其余 GPIO 以 `.syscfg` 的命名映射为准。

`Trace_Timer` 使用 TIMG7，周期 5 ms；`TIMER_0` 保存的定时器解为 TIMG12，周期 10 ms。`SYSCTL.forceDefaultClkConfig=true`，该文件没有逐项声明所有外设时钟等于系统时钟，具体频率应在生成结果中核对。

## 常见依赖问题

- 缺少 DriverLib/CMSIS 头文件：先核对外部 SDK 产品和安装目录变量，再检查包含路径。
- 缺少库或符号：核对 `.cproject` 的 SDK 库变量与所选目标，不通过复制不明版本库解决。
- 引脚变化：比较重新生成前后的配置文件，尤其检查自动求解的 I2C、SWD 和 GPIO。
