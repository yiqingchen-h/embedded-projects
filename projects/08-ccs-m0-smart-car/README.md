# MSPM0G3507 竞赛控制小车

基于 TI MSPM0G3507，当前公开 v1.2B 源码，包含循迹、云台、电磁铁、IMU 与视觉串口接入。

## 版本与入口

- [最新版本(v1.2B)/源码/](最新版本(v1.2B)/源码/)：当前展示入口，包含 CCS/SysConfig 工程、`Stepping_Trace.c` 和 `HardWare/`。
- [编译说明](最新版本(v1.2B)/编译说明.md)：CCS 导入入口、SDK 依赖及当前引脚配置。

底盘使用步进电机控制与灰度循迹；视觉侧通过串口传入 `OpenCv_Rx` 结果，MCU 在显示和任务流程中使用。视觉识别运行在外部设备。

## 使用

在 CCS 中导入最新版源码目录，按 `.ccsproject`、`.cproject` 和 `.syscfg` 配置相应 TI SDK、编译器及引脚。

微步数表示驱动设置；机械定位精度和调整效果需在具体负载与测量条件下验证。
