# STM32H7 多旋翼飞控搭建与调试

此目录提供基于 WFG100A 参考方案的飞控搭建展示，使用现有飞控固件和 Mission Planner 进行配置与调试。个人工作范围为器件装配、固件烧录、外设联调、参数调整和试飞记录；飞控算法与固件来源不表述为个人从零开发。

## 本目录内容

当前提供 `media/` 中的实物照片和试飞视频，以及本说明，未提供飞控固件源码、原理图或 BOM。涉及具体固件分支、硬件配置和参数时，应以原始工程与调试记录为准。

## 硬件与复现边界

展示基于 STM32H7/WFG100A 参考方案，具体传感器、接口和电源连接需要对应版本的原理图与板卡说明。本目录没有完整 BOM 和接线图，不根据照片补造引脚表。

## 固件构建与烧录

本目录不含固件源码，因此没有可在此目录执行的构建命令。重新构建需取得实际使用的上游固件版本、目标板定义及其依赖。

已有固件的烧录与参数设置使用对应板卡流程和 Mission Planner。烧录前确认固件目标、引导程序和板卡型号一致；参数、校准与试飞条件以实际调试记录为准。展示视频不替代这些复现资料。
