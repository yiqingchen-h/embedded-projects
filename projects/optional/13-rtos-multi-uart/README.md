# STM32 三路 UART 环形缓冲通信

当前运行入口是三路串口的轮询转发实验。目录保留 FreeRTOS 文件，但 [main.c](工程文件/user/main.c) 没有启动 RTOS 调度器，因此不将其表述为已接入 FreeRTOS 的通信系统。

## 当前实现

主程序将三路 UART 配置为 921600 bps，在主循环消费收发位置描述并调用中断发送接口。[UART.h](工程文件/HardWare/UART.h) 定义每路接收和发送数组为 2048 字节，单次最大接收值为 256；环形描述项管理缓冲位置。

源码位于 [工程文件/](工程文件/)，当前未提供 `.uvprojx`；复现时需要为实际芯片建立工程并添加启动、HAL/CMSIS 与应用源文件。波特率为初始化配置，不代表已验证的持续有效吞吐；未给出 CPU 占用率或并发丢包率结论。
