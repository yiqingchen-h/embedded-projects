# STM32 电机与姿态接口实验

此目录保留早期自动行驶小车相关外设和控制试验。Keil 入口为 [project.uvprojx](project.uvprojx)，当前主程序为 [User/main.c](User/main.c)。

当前入口初始化 PWM 并写入固定比较值；DMP、姿态读取、定时控制和灰度初始化调用仍处于注释状态，OLED 显示调用也需要核对初始化。不能将这个快照直接表述为已接入平衡与巡线控制的整车程序。

`Hard Ware/`、`System/` 保留 MPU6050、PWM 等实现。PWM 频率、姿态采样频率和控制环频率是不同概念；启用实验功能时需按实际调用链分别确认。

## 硬件与构建

工程目标为 STM32F103C8，Cortex-M3；工程配置的 Flash 为 64 KiB、RAM 为 20 KiB。PWM 电机输出为当前运行入口；姿态、灰度和显示接口代码仍保留在 `Hard Ware/`。当前入口没有启用这些模块的完整初始化，接线完成不表示功能已经接入。

1. 使用 Keil MDK 打开本目录 `project.uvprojx`，保留工程声明的目标和源文件分组。
2. 配置工程对应的 Arm 编译器及 STM32F1 器件包；核对 `Start/` 启动文件、系统时钟和头文件路径。主程序为 `User/main.c`。
3. 在 MDK 中构建所选目标，检查编译与链接诊断。构建目录留在本地，不加入公开源码。

## 下载与运行

选择实际使用的 SWD 调试器（例如 ST-Link 或 J-Link），核对 STM32F103C8 的 Flash 算法和起始地址 `0x08000000`。连接 SWDIO、SWCLK、GND 和参考电压，先断开电机执行电源进行下载，再核对驱动方向与输入状态。

本轮只静态核对工程引用，未执行构建或烧录；当前功能范围以上方实际主程序说明为准。
